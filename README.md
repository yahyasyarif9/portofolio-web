## 🎯 Tujuan Praktikum

Website ini dibuat untuk memenuhi requirement Praktikum 2 dengan fitur-fitur:

1. ✅ Layout web dengan header, navigasi, main/content, sidebar, dan footer
2. ✅ Navigasi di sidebar dengan quick links
3. ✅ Halaman profil/portofolio personal
4. ✅ Responsive design dengan grid dan media queries
5. ✅ Animasi running text (teks berjalan)
6. ✅ Bootstrap untuk styling komponen (button, badge, dll)

## 🚀 Fitur Website

### Layout & Struktur
- **Header Section**: Hero section dengan foto profil, nama, deskripsi, dan social links
- **Navigation Bar**: Sticky navigation dengan smooth scrolling
- **Sidebar**: Informasi singkat, quick links, dan status badge
- **Main Content**: Section About, Skills, Projects, dan Contact
- **Footer**: Informasi kontak dan social media links
- **Running Text**: Animasi teks berjalan di bawah header

### Desain & Styling
- **Tema Warna**: Biru profesional (#0d6efd)
- **Typography**: Google Fonts - Poppins
- **Icons**: Bootstrap Icons
- **Framework**: Bootstrap 5.3.2
- **Custom CSS**: Style responsif dan animasi

### Responsive Design
- ✅ Desktop (>992px)
- ✅ Tablet (768px - 991px)
- ✅ Mobile (576px - 767px)
- ✅ Small Mobile (<576px)

### Animasi & Interaksi
- Fade in animations (fadeInLeft, fadeInRight, fadeInUp)
- Running text dengan @keyframes
- Hover effects pada cards, buttons, dan links
- Smooth scrolling navigation
- Back to top button
- Scroll reveal animation
- Parallax effect pada header
